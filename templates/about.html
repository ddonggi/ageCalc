운영 기준

콘텐츠 운영 원칙

AgeCalc는 계산 결과만 보여주는 사이트가 아니라, 계산 기준과 해석에 필요한 설명 글까지 함께 제공하는 생활 정보 서비스를 지향합니다.

바로 답변

AgeCalc는 어떻게 콘텐츠를 운영하나요?

AgeCalc는 계산 결과, 계산 기준, 참고 출처, 수정 가능성을 함께 표시합니다. 숫자만 자동 생성하는 페이지보다 사용자가 결과를 해석할 수 있는 설명과 다음 경로를 우선합니다.

편집 기준

AgeCalc 편집팀이 내용을 작성하고 AgeCalc 운영자가 자체 검수합니다.

1 콘텐츠 운영 원칙
  • 원문을 직역하거나 단순 요약한 글은 공개하지 않습니다.
  • 계산기와 연결되는 활용 맥락이 분명한 설명 글만 공개합니다.
  • 정책·제도 정보는 공식 기관 안내를 우선 확인하도록 안내합니다.
2 출처 사용 방식
  • 모든 공개 글에는 참고한 자료 또는 출처 링크를 함께 표기합니다.
  • 연구·정책·보도자료는 핵심 사실을 교차 확인한 뒤 이해하기 쉬운 글로 다시 씁니다.
  • 과장되거나 불안감을 조장하는 표현은 지양합니다.
3 문의 및 수정
  • 문의: {{ contact_email }}
  • 오류 제보가 접수되면 검토 후 글을 수정하거나 비공개 처리합니다.
  • 주요 수정이 있는 글은 최종 수정일을 표시합니다.

계산식과 설명은 이렇게 검수합니다

계산 로직을 변경할 때는 대표값과 경계값을 자동 테스트하고, 계산 결과와 화면 설명을 대조합니다.

1 계산식 확인
  • 생일 전후, 윤년, 월말, 입학 기준처럼 결과가 달라지는 경계값을 확인합니다.
  • 대표값과 경계값을 자동 테스트해 기존 계산 결과가 바뀌지 않았는지 검사합니다.
  • 계산 결과와 화면 설명을 대조해 공식과 예시가 서로 다른 경우를 찾습니다.
2 정책·제도 확인
  • 정책·제도 내용은 공식 기관 자료를 우선 확인합니다.
  • 매년 1월·7월에 정기 확인하고, 공식 변경 공지 확인 시 수시로 다시 검수합니다.
  • 페이지의 기준 확인일과 최종 수정일은 서로 다른 의미로 관리합니다.
3 오류 수정 흐름
  1. 문의 페이지에서 오류 접수
  2. 재현·공식 근거 확인
  3. 필요한 내용을 수정 또는 비공개
  4. 최종 수정일과 내부 변경 기록 갱신

이 과정은 AgeCalc 운영자의 자체 검수이며 법률·의료·수의학 전문가의 감수를 의미하지 않습니다. 중요한 결정에는 관계 기관 또는 해당 분야 전문가의 최신 안내를 확인하세요.
