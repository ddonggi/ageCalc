# AgeCalc 후속 개선 작업 체크리스트

## 사용 방법

이 문서는 후속 Plan Mode에서 한 항목씩 선택하기 위한 작업 목록입니다. 각 항목은 독립적인 조사·구현·검증 단위로 나눴습니다. 운영 배포, `main` 병합, 원격 push, Search Console 제출, 네이버 서치어드바이저 변경은 별도 승인 전까지 수행하지 않습니다.

우선순위는 다음과 같습니다.

- `P0`: 색인 신호나 측정 신뢰도에 직접 영향을 주므로 먼저 처리
- `P1`: 실제 노출 데이터로 개선 가능성이 확인된 핵심 페이지
- `P2`: 신뢰·GEO·내부 탐색을 강화하는 후속 작업

체크된 항목은 다시 구현하지 않고 건너뜁니다. 다만 후속 항목의 전제조건이거나 데이터가 바뀐 경우에는 완료 상태를 해제하지 않은 채 필요한 부분만 재검증합니다. `P0-5`에서는 현재 확보한 데이터로 기준표를 먼저 만들고, 2026-08-11 변경 후 14일·28일 비교는 별도 관찰 일정으로 남겨 다른 개선 작업을 막지 않습니다.
