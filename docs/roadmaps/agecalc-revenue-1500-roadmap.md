# AgeCalc 월 $1,500 수익 성장 로드맵

> 작성 기준일: 2026-08-23<br>
> 목표 기간: 12개월<br>
> 핵심 시장: 대한민국 검색 사용자<br>
> 목표 수익: 월 $1,500 이상(계획 환율 1달러=1,386.89원 적용 시 약 208만 원, 운영 목표 210만 원)<br>
> 권장 수익 구조: AdSense 70% + 문맥형 제휴 30%

## 1. 로드맵 사용 원칙

이 문서는 AgeCalc를 단순 나이 계산기에서 나이·가족·육아·교육·기념일·임신·출산·은퇴 시점을 연결하는 인생 일정 계산 플랫폼으로 확장하기 위한 실행 체크리스트다.

- 저장소에서 확인된 현재 구조와 검색 원천 데이터를 기준선으로 사용한다.
- 페이지 RPM과 미래 수익은 실적이 아니라 계획 가정으로 관리한다.
- 새 계산기는 검색 수요, 기존 사용자와의 관련성, 내부링크 가능성을 통과한 경우에만 만든다.
- 의료·금융·행정 결과는 참고 정보로만 제공하고 공식 조회를 대체하지 않는다.
- 검색어만 바꾼 대량 페이지와 AgeCalc 범위를 벗어난 계산기는 만들지 않는다.
- 모든 출시에는 측정 이벤트, 공식 출처, 개인정보 검토, 4~8주 평가 기준이 따라야 한다.

## 15. 가장 중요한 단일 작업

모든 계산기에 다음 퍼널을 일관되게 계측한다.

`calculator_start → calculator_complete → next_path_click → second_page_view → affiliate_click`

이 퍼널이 구축되기 전에는 페이지 수를 빠르게 늘리지 않는다. AgeCalc의 월 $1,500 달성 가능성을 가장 크게 높이는 일은 어떤 계산 완료가 두 번째 페이지와 실제 수익으로 이어지는지 먼저 확인하는 것이다.
