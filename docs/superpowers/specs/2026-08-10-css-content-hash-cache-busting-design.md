# CSS 콘텐츠 해시 캐시 무효화 설계

## 목표

CSS가 배포될 때 파일 내용이 바뀌면 정적 URL도 자동으로 바뀌게 한다. 사용자는 브라우저 캐시를 직접 지우지 않아도 최신 모바일 레이아웃을 받고, 변경되지 않은 CSS는 기존 30일 캐시의 성능 이점을 유지한다.

## 현재 문제

- Nginx는 `/static/` 파일을 30일 동안 캐시한다.
- 66개 템플릿이 공통 `style.css`에 수동 버전 문자열을 사용한다.
- CSS를 수정하면서 문자열을 바꾸지 않으면 기존 방문자는 최대 30일 동안 구버전을 볼 수 있다.
- 페이지별 게임 CSS 일부는 버전 문자열이 없어 같은 위험이 있다.

## 설계

### URL 생성

Flask에 `versioned_static(filename)` 템플릿 전역 함수를 추가한다. 함수는 정적 파일의 SHA-256 콘텐츠 해시 앞 12자를 계산해 다음 형식의 URL을 반환한다.

```text
/static/css/style.css?v=<12-character-content-hash>
```

해시는 파일 내용에만 의존한다. 수정 시각이나 프로세스 시작 시각은 사용하지 않으므로 동일한 배포물은 서버 재시작 후에도 같은 URL을 만든다.

### 캐시와 오류 처리

- 계산 결과는 프로세스 메모리에 파일명별로 캐시해 요청마다 파일을 다시 읽지 않는다.
- 정적 경로 밖으로 벗어나는 파일명은 허용하지 않는다.
- 파일이 없거나 읽을 수 없으면 예외로 페이지 렌더링을 중단하지 않고 일반 `url_for('static', filename=...)` URL을 반환한다.
- Nginx의 기존 30일 캐시 정책은 유지한다.
- 이미 `no-cache, must-revalidate`인 JavaScript 정책은 변경하지 않는다.

### 템플릿 적용 범위

- 모든 `<link rel="stylesheet">`의 로컬 CSS 경로를 `versioned_static(...)`으로 전환한다.
- 공통 `style.css`의 기존 수동 `?v=...` 문자열을 제거한다.
- 게임별 CSS와 기타 로컬 CSS도 같은 자동 해시 방식을 적용한다.
- Google Fonts 같은 외부 스타일 URL은 변경하지 않는다.
- 이미지, manifest, JavaScript URL은 이번 변경 범위에서 제외한다.

## 테스트

- 같은 내용의 CSS는 같은 URL을 반환한다.
- CSS 내용이 달라지면 버전 값이 달라진다.
- 버전 값은 SHA-256 앞 12자와 일치한다.
- 존재하지 않는 파일은 일반 정적 URL로 안전하게 폴백한다.
- 공개 페이지가 수동 CSS 버전 문자열 없이 해시가 포함된 CSS URL을 렌더링한다.
- 전체 테스트 스위트를 `ADSENSE_REVIEW_MODE=true`로 실행한다.

## 배포 결과

배포 후 HTML은 새 콘텐츠 해시 URL을 즉시 제공한다. 기존 브라우저 캐시에는 이전 URL이 남아 있어도 새 HTML이 다른 URL을 요청하므로 최신 CSS가 바로 반영된다.
