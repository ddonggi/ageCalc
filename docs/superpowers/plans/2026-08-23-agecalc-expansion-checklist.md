# AgeCalc Expansion Checklist Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AgeCalc를 계산기 개수 경쟁이 아닌, 한 번 입력한 날짜로 나와 가족의 생애 일정을 이어서 확인하는 생활 계산 플랫폼으로 확장한다.

**Architecture:** 기존 Flask/Jinja와 공개 URL을 유지하고 신규 기능을 작은 배포 묶음으로 추가한다. 날짜 계산은 결정적 함수로 테스트하고, 입력값 재사용은 서버 전송 없이 브라우저 저장소에서 명시적 동의 후 제공한다. 각 묶음은 계산 완료율·관련 도구 이동률·재방문 신호를 확인한 뒤 다음 단계로 진행한다.

**Tech Stack:** Python 3, Flask 2.3, Jinja2, vanilla JavaScript/CSS, unittest

**Spec:** `docs/AGECALC_SEO_ADSENSE_LIFE_PLATFORM_STRATEGY.md`

**Related UI roadmap:** `docs/roadmaps/css-layout-checklist.md`

## Global Constraints

- 핵심 포지셔닝은 `나와 가족의 시간을 계산하고 관리하는 곳`으로 유지한다.
- 신규 페이지는 기존 페이지와 독립적인 검색 의도와 고유 결과를 가져야 한다.
- 생년월일 등 개인정보 성격의 값은 분석 도구에서 마스킹하고 기본적으로 서버에 저장하지 않는다.
- 의료·세금·법률 판단 기능은 공식 출처, 기준일, 검수·갱신 책임자가 준비되기 전까지 출시하지 않는다.
- AdSense는 승인 완료 상태이며, 콘텐츠 경고는 개선 목록으로 관리하고 콘텐츠 오류와 정책 위반만 출시를 차단한다.
- 기존 공개 URL은 이 계획만을 이유로 변경하지 않는다.
- 모든 기능은 모바일 360px 화면, 키보드 탐색, 오류 안내, 빈 상태를 함께 검증한다.
- 각 배포 묶음은 관련 테스트와 전체 테스트를 모두 통과해야 완료로 표시한다.

- [ ] 생일을 모를 경우 결과에 `추정` 표시와 오차 안내를 제공한다.
- [ ] 강아지·고양이 생애단계(유년기·성년기·노년기)를 표시한다.
- [ ] 건강검진·예방접종 정보는 공식 수의학 출처와 검수 체계를 확보한 뒤 별도 배치로 출시한다.
- [ ] 같은 반려동물 값을 브라우저에 저장하는 기능은 명시적 동의와 삭제 기능을 갖춘다.

- [ ] 체형별 계산식과 출처가 결과 가까이에 표시된다.
- [ ] 추정값을 확정적 의료 정보처럼 표현하지 않는다.
