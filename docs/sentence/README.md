# 카테고리·계산기 문장 점검

카테고리 5개와 계산·조회 도구 22개의 한국어 UI 문구를 `humanize-korean` fast mode 기준으로 점검한 결과입니다.

- 공통 헤더·푸터·쿠키 배너 문구는 제외했습니다.
- 숫자, 날짜, 계산 기준, 기관명, 법적·의학적 고지의 의미는 바꾸지 않았습니다.
- `높음`은 첫 화면이나 핵심 안내에서 바로 읽히는 문장, `보통`은 반복되거나 다소 딱딱한 문장, `낮음`은 선택적으로 다듬을 문장입니다.
- 이 문서는 수정 제안 목록이며, 실제 템플릿 문구는 변경하지 않았습니다.
