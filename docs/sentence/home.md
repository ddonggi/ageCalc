# 메인 페이지 (`/`) 문장 점검

메인 본문 UI 문구만 `humanize-korean` strict mode로 점검했습니다. 공통 헤더·푸터·쿠키 배너와 계산 결과값은 제외했으며, 이 문서는 제안 목록이므로 실제 템플릿 문구는 바꾸지 않았습니다.

| 번호 | 우선순위 | 기존문구 | 수정문구 | 이유 |
| --- | --- | --- | --- | --- |
| 1 | 높음 | 생년월일부터 중요한 생활 시점까지 차분하게 확인하세요. | 생년월일로 현재 나이와 생활에 필요한 날짜를 확인하세요. | ‘중요한 생활 시점’, ‘차분하게’가 추상적이라 첫 화면에서 무엇을 할 수 있는지 바로 알기 어렵습니다. |
| 2 | 높음 | 계산 결과를 가족, 학교, 기념일, 건강과 앞으로의 생애 시점으로 연결합니다. | 나이, 학교, 기념일, 반려동물 관련 계산을 한곳에서 찾아보세요. | ‘계산 결과를 연결한다’는 표현보다 사용자가 탐색할 카테고리를 직접 말하는 편이 자연스럽습니다. 현재 화면의 반려동물 카테고리도 반영합니다. |
| 3 | 보통 | 날짜를 입력하지 않고 출생연도와 입학 시점, 띠 기준을 바로 확인하세요. | 날짜 입력 없이 출생연도, 입학 시점, 띠를 바로 확인하세요. | 조사와 명사 나열을 줄여 짧은 안내 문구로 읽기 쉽게 만듭니다. |
| 4 | 보통 | 몇 년생인지로 현재 나이 확인 | 출생연도별 현재 나이 확인 | ‘몇 년생인지로’의 조사 결합이 어색합니다. 링크가 제공하는 기준도 더 분명해집니다. |
